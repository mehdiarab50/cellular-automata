# شبیه‌ساز اتوماتای سلولی سه‌بعدی (بازنویسی شده)

این پروژه یک شبیه‌ساز اتوماتای سلولی سه‌بعدی تعاملی است که با استفاده از کتابخانه‌های Three.js و dat.GUI در جاوااسکریپت پیاده‌سازی شده است. این نسخه بازنویسی شده، از CDN برای بارگذاری کتابخانه‌ها استفاده می‌کند و شامل منطق کامل شبیه‌سازی و کنترل پنل کاربر است.

## ویژگی‌های اصلی

*   **شبکه سه‌بعدی:** ایجاد و نمایش یک شبکه از سلول‌ها در فضای سه‌بعدی.
*   **تعامل با ماوس:** امکان روشن/خاموش کردن سلول‌ها با کلیک ماوس.
*   **کنترل دوربین:** استفاده از `OrbitControls` برای چرخش، بزرگنمایی و جابجایی دوربین.
*   **کنترل پنل (dat.GUI):**
    *   **کنترل شبیه‌سازی:** شروع، توقف، اجرای گام به گام و تنظیم سرعت شبیه‌سازی.
    *   **کنترل شبکه:** بازنشانی شبکه به حالت اولیه (تمام سلول‌ها خاموش) و یا تنظیم تصادفی وضعیت سلول‌ها.
    *   **تعریف قوانین سفارشی:** امکان تعریف قوانین تولد (Birth) و بقا (Survival) برای اتوماتای سلولی با استفاده از نماد استاندارد B/S.
*   **بارگذاری از CDN:** کتابخانه‌های Three.js و dat.GUI از طریق CDN بارگذاری می‌شوند.

## نحوه اجرا

**مهم:** به دلیل استفاده از ماژول‌های جاوا اسکریپت (`<script type="module" src="js/main.js"></script>`)، این پروژه **باید از طریق یک وب سرور محلی اجرا شود.** باز کردن مستقیم فایل `index.html` از سیستم فایل در مرورگر احتمالاً به دلیل محدودیت‌های امنیتی CORS برای ماژول‌ها کار نخواهد کرد.

در اینجا چند روش رایج برای راه‌اندازی یک وب سرور محلی در دایرکتوری ریشه پروژه آورده شده است:

1.  **با استفاده از Python:**
    *   اگر Python 3 نصب است، دستور زیر را در ترمینال یا خط فرمان اجرا کنید:
        ```bash
        python -m http.server
        ```
    *   اگر Python 2 نصب است:
        ```bash
        python -m SimpleHTTPServer
        ```
    *   سپس مرورگر خود را باز کرده و به آدرس `http://localhost:8000` (یا پورت دیگری که نمایش داده می‌شود) بروید.

2.  **با استفاده از Node.js و `http-server`:**
    *   ابتدا `http-server` را به صورت سراسری نصب کنید (اگر قبلاً نصب نکرده‌اید):
        ```bash
        npm install -g http-server
        ```
    *   سپس در دایرکتوری ریشه پروژه، دستور زیر را اجرا کنید:
        ```bash
        http-server
        ```
    *   آدرس (معمولاً `http://localhost:8080`) در ترمینال نمایش داده می‌شود که می‌توانید در مرورگر باز کنید.
    *   یا می‌توانید از `npx` برای اجرای بدون نصب سراسری استفاده کنید:
        ```bash
        npx http-server
        ```

3.  **با استفاده از افزونه "Live Server" در VS Code:**
    *   اگر از ویرایشگر VS Code استفاده می‌کنید، می‌توانید افزونه "Live Server" را نصب کنید.
    *   پس از نصب، روی فایل `index.html` در VS Code کلیک راست کرده و گزینه "Open with Live Server" را انتخاب کنید.

## نحوه استفاده از کنترل پنل

کنترل پنل در گوشه بالا-راست صفحه نمایش داده می‌شود و شامل بخش‌های زیر است:

*   **Simulation Controls:**
    *   **Run Simulation:** شبیه‌سازی را شروع یا متوقف می‌کند.
    *   **Speed (ms):** سرعت شبیه‌سازی را بر حسب میلی‌ثانیه بین هر گام تنظیم می‌کند. مقادیر کمتر به معنای سرعت بیشتر است (مثلاً 50ms سریع‌تر از 500ms است).
    *   **Step Forward:** شبیه‌سازی را دقیقاً یک گام به جلو می‌برد، حتی اگر شبیه‌سازی متوقف باشد.
*   **Grid Controls:**
    *   **Reset Grid:** تمام سلول‌های شبکه را به حالت خاموش (مرده) بازنشانی می‌کند.
    *   **Randomize Grid:** وضعیت سلول‌های شبکه را به صورت تصادفی تنظیم می‌کند (حدود 30% سلول‌ها روشن می‌شوند).
*   **Rules (B/S Notation):**
    *   **Birth (B):** یک رشته از اعداد (0 تا 26) جدا شده با کاما وارد کنید (مثلاً "3" یا "5,6"). یک سلول مرده اگر تعداد همسایگان زنده‌اش دقیقاً یکی از این اعداد باشد، در گام بعدی زنده (متولد) می‌شود.
    *   **Survival (S):** یک رشته از اعداد (0 تا 26) جدا شده با کاما وارد کنید (مثلاً "2,3" یا "4,5"). یک سلول زنده اگر تعداد همسایگان زنده‌اش دقیقاً یکی از این اعداد باشد، در گام بعدی زنده باقی می‌ماند. در غیر این صورت، می‌میرد (از تنهایی یا ازدحام بیش از حد).

## کتابخانه‌های استفاده شده

*   [Three.js](https://threejs.org/): برای رندرینگ سه‌بعدی و مدیریت صحنه. (بارگذاری از CDN)
*   [dat.GUI](https://github.com/dataarts/dat.gui): برای ایجاد رابط کاربری گرافیکی کنترل پنل. (بارگذاری از CDN)

## محدودیت‌های شناخته شده (برای این نسخه)

*   **عملکرد:** با افزایش ابعاد شبکه (و در نتیجه تعداد کل سلول‌ها)، عملکرد شبیه‌سازی ممکن است به طور قابل توجهی کاهش یابد. این به دلیل استفاده از اشیاء `THREE.Mesh` مجزا برای هر سلول است. برای شبکه‌های بسیار بزرگ، استفاده از تکنیک‌هایی مانند `InstancedMesh` برای بهینه‌سازی عملکرد ضروری خواهد بود.
*   **سادگی قوانین:** سیستم قوانین فعلی فقط بر اساس تعداد همسایگان عمل می‌کند و از انواع پیچیده‌تر قوانین اتوماتای سلولی (مانند قوانین نسلی یا با وزن‌دهی همسایگان) پشتیبانی نمی‌کند.
